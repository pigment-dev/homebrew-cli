# Pigment Dev command-line tools for Homebrew

Command-line tools by [Pigment Dev](https://pigment.dev), for macOS and Linux.

```sh
brew install pigment-dev/cli/pdrclone
```

| Formula | Installs |
|---|---|
| `pdrclone` | `pdrclone` and `pdrcloned`, the sync service and CLI of [rClone](https://pigment.dev/products/rclone/). Run the service with `brew services start pigment-dev/cli/pdrclone`. |
